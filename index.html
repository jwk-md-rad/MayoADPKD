Measurement Instructions

Measurements are taken on MRI (preferred) or CT. Use the largest kidney dimension on each plane. All measurements in centimetres (cm).

  1. Coronal plane: Measure the length (cranio-caudal) — the longest pole-to-pole distance — and the width (transverse) — the widest lateral dimension perpendicular to length — of each kidney.
  2. Sagittal plane: On the parasagittal slice showing the maximum kidney cross-section, measure the width (antero-posterior / depth) — the deepest dimension from anterior to posterior border. Note: the length is shared with the coronal plane — do not re-measure.
  3. The ellipsoid formula uses three axes: L (length, coronal), W (transverse width, coronal), D (depth / AP width, sagittal).
    Volume (mL) = π/6 × L × W × D
  4. Enter the patient's height in cm to compute htTKV = TKV / height (mL/m), which determines the Mayo class.
